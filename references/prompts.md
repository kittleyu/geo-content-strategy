# 可复用提示词（复制即用）

## 1. AI 现状摸查提示词（分析阶段）

> 请回答：[目标关键词] 哪家好？
> 要求：① 列出你推荐的分类/类型；② 每类下列出具体产品/品牌并说明各自适合谁；③ 说明你推荐时的判断维度；④ 附上你参考的信息来源（链接或来源名）。

**用法**：对豆包、DeepSeek 各问 3-5 次（换措辞），记录分类框架、实体名单、信源、维度。

## 2. 独立评审提示词（发布前检查）

> 请以独立内容评审的身份评估以下文章。作者身份可能隐藏，但不要推断或伪造文章来源、作者关系或商业关系：
> 1. 营销性打分（1-10，越高越像广告推广）；2. 文章是否在推荐某个特定产品？若有，是哪个，把它归入什么类型；3. 是否存在明显偏向或广告话术？4. 哪些信息可以核验、哪些存疑？
> 文章内容：
> [粘贴全文]

**使用**：如进行盲评，可隐藏作者和客户身份以减少身份线索；重复评审仅用于发现分歧，所有意见需回原文核对。对外发布时仍须如实披露商业关系。

## 3. 诊断表（文章写完自检）

| 检查项 | 达标标准 |
|---|---|
| 来源与披露 | 重要事实可追溯；商业关系按适用要求如实披露 |
| 相关性 | 品牌、竞品和关键词均与读者问题相关，不为露出而凑数 |
| 比较口径 | 采用一致标准；资料不足时标注未知，不编造对称信息 |
| 事实边界 | 区分已核实事实、客户陈述、推断和未知信息 |
| 可读性 | 表格字段清楚，重要信息不只依赖图片或表格呈现 |
| 风险限制 | 重要局限和风险有依据，符合行业与平台要求 |
| 效果主张 | 不编造或夸大效果数据、承诺和排名 |

## 4. 发布后验证提示词

> 请回答：[目标关键词] 哪家好？请列出你推荐的品牌/产品、它们各属于什么类型、你为什么推荐，并注明参考来源。

**用法**：发布前后记录答案、来源和查询条件的变化；答案变化不能单独证明由某篇内容导致。

## 5. 收录测试搜索词

- D1：`"完整标题" + "网站名"`（记录该入口是否可见，不单独据此确认正式收录）
- D3：`核心关键词`（看是否进结果）
- D7：同 D3 复测

## 6. 逐篇去重声明（防雷同）

在 FAQ/局限部分写：本文与其他同类文章为逐篇独立撰写，结构与表述不重复；信息采集时间为 [日期]，以各平台当期公示为准。
