# 可复用提示词（复制即用）

## 1. AI 现状摸查提示词（分析阶段）

> 请回答：[目标关键词] 哪家好？
> 要求：① 列出你推荐的分类/类型；② 每类下列出具体产品/品牌并说明各自适合谁；③ 说明你推荐时的判断维度；④ 附上你参考的信息来源（链接或来源名）。

**用法**：对豆包、DeepSeek 各问 3-5 次（换措辞），记录分类框架、实体名单、信源、维度。

## 2. 盲评评估提示词（发前验证）

> 下面是网上搜到的一篇文章，请以客观读者的身份评估：
> 1. 营销性打分（1-10，越高越像广告推广）；2. 文章是否在推荐某个特定产品？若有，是哪个，把它归入什么类型；3. 是否存在明显偏向或广告话术？4. 哪些信息可以核验、哪些存疑？
> 文章内容：
> [粘贴全文]

**铁律**：绝不说明这是自己写的；同篇评 ≥2 次，只信重复意见；每条意见回原文核对。

## 3. 诊断表（文章写完自检）

| 检查项 | 达标标准 |
|---|---|
| 首现位置 | 主推品牌在全文前 5% 出现 |
| 开篇声明 | 有"选取标准就是信息可查"、点名机构、数据带来源+时间 |
| 分类对位 | 用 AI 的分类词，主推品牌不单独占一类 |
| 五要素 | 每家都有：分类词/名称/数据/适合谁/局限 |
| 篇幅对等 | 各实体篇幅差 <70 字 |
| 去魅段落 | 有拆穿行业话术的段落，对所有机构不利 |
| 表格复述 | 表格关键信息在正文有文字版 |
| 匹配建议 | 每条并列 2-3 家，全篇 ≥2 条带出主推品牌 |
| 效果数据 | 无提分率/治愈率/收益率类数据 |
| 合规与劝退 | 政策文件写全称、有劝退项、有局限声明 |

## 4. 发布后验证提示词

> 请回答：[目标关键词] 哪家好？请列出你推荐的品牌/产品、它们各属于什么类型、你为什么推荐，并注明参考来源。

**用法**：对比发布前后的回答差异，看主推品牌是否进答案、归对类、有理由。
